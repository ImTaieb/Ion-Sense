# ION Voice Reference

Chatterbox-Turbo clones the speaker in `ion-reference.wav`. **The stock
Chatterbox voice is never used as ION** — without a readable reference the
voice service reports `failed/reference-missing` and the HUD speaks with the
male Web Speech fallback instead.

## Current file: INTERIM SYNTHETIC

`ion-reference.wav` is currently generated by `make-interim-reference.ps1`
(Microsoft David, local SAPI, original text). It exists so the neural pipeline
speaks with a **male** identity, and is explicitly a stopgap.

## Target reference (replacement required)

A refined British male, early 30s–40s, low-mid register, precise consonants,
calm authority — JARVIS-**like character**, NOT a clone of any actor.

Recording requirements:

- clean, single speaker, dry (minimal room echo)
- no music, no background noise, no processing/compression
- 10–20 seconds of calm natural speech, varied consonants/vowels, natural pauses
- no whispering, shouting, movie dialogue, or reverberant clips

Replace the file and restart ION Sense. The service fingerprints the WAV and
invalidates its synthesis cache automatically. Also clear
`%LOCALAPPDATA%\ion-sense\voice-lastgood` when replacing the speaker: this offline
fallback cannot verify a new reference fingerprint while the service is unavailable.
